## 가이드 수치(테스트로 고정)

- 퍼센트: 40% → 50% = +10 포인트 = +25%; 125 → 100 = −20%; 100에서 20% 뒤 10% 할인 = 72(−28%). `calculatePercentage`로 검증.
- CSS: 24px = 1.5rem(root 16px), 2.4rem(root 10px); 1.25em 중첩 = 1.5625; 360px = 25vw(1440px); 12pt = 16px.
- 비밀번호: 10×log2(91) = 65.1, 16×log2(26) = 75.2, 16×log2(62) = 95.3, 16×log2(91) = 104.12 비트; 네 종류를 모두 포함하는 16자의 정확한 값 = 103.86 비트(포함–배제).
- QR: 38자·41자·41자 샘플 = 29 × 29 모듈, vCard 100자 = 41 × 41 모듈. 4개 샘플 모두 생성 PNG를 ZXing-C++ 3.1.1로 읽어 입력과 일치(`public/guides/qr-format-results.json`). 디지털 이미지만 확인, 인쇄·카메라 스캔은 확인하지 않음.

## 열린 확인

- 번역은 AI 작성이며 원어민 검수 없음. 다시 거절되면 검수 안 된 언어의 noindex를 검토한다.
- 운영자 이름: `NEXT_PUBLIC_SITE_OPERATOR` 값은 사용자가 정해야 한다(미설정).
- 실제 방문·유입은 코드로 해결되지 않는다(미확인).
- 미착수: P2(CMP/TCF, Open-Meteo 키, IPinfo 토큰·`?ip=` 제한, 면책 위치), P3(`headers()` 정적 렌더링).
