# AdSense 콘텐츠 보강 적용 결과

적용일: 2026-10-07. 기준 커밋: `fe2f727`. 이 문서는 로컬 작업과 검증 결과이며, Google 승인 결과나 운영 배포 완료 기록이 아니다.

## 적용 범위

| 영역 | 적용 내용 |
| --- | --- |
| 결과 정확성 | 단위·픽셀 정수의 끝자리 0 보존, 언어별 환율 소수 입력, 삽입·삭제 후 행 정렬, 0 기준 증감률 차단 |
| 연봉 계산 | 국세청 월 간이세액표 646구간과 고액 급여 산식 적용. 잘못된 가족·자녀 수와 급여를 넘는 비과세 입력에는 실수령액·세액을 표시하지 않음 |
| 기타 입력·결과 | HEX 미리보기·복사값 일치, UTF-8이 아닌 Base64와 문법 오류 구분, 줄바꿈·탭 뒤 Title Case, 비밀번호의 선택 문자 종류 포함 및 미선택 차단, 더미 텍스트 1~100문단 제한 |
| 이미지 압축 | JPG·PNG·WebP 및 파일별 10 MiB 제한, 실패 파일명 유지, PNG 품질 미적용 안내. 기존 순차 처리·미리보기 정리 유지 |
| QR·바코드 | 현재 UI 요청을 POST로 변경해 원문을 URL에서 제외. QR 여백 추가. 입력 변경 시 이전 결과 제거, 취소된 요청의 상태 덮어쓰기 방지 |
| 외출 지표 | 모델 예보와 실시간 관측 구분, 한국 꽃가루 미지원 명시, 예보 유효 시각과 조회 시각 분리, 15분 재조회, 오래된 값·누락·장애 안내, CAMS 출처 표기 |
| 도구 콘텐츠 | 17개 도구의 안내를 기능·제약·예시·출처 중심으로 10개 언어에 적용. 반복 장점·일반 FAQ 및 동일 본문 중복 제거. 기존 별도 검수 5개 도구 콘텐츠는 유지 |
| 독립 가이드 | JSON 큰 정수, 유니코드 글자 수, PNG 품질과 파일 크기 3편을 10개 언어로 추가. 홈·관련 도구·소개에서 연결 |
| 운영 안내 | QR·바코드 서버 처리와 전광판 문구의 기기 저장을 개인정보 안내에 반영. 소개에 실제 검증 방법·오류 접수 연결 추가 |
| URL·모바일 | 기존 언어·도구 URL 유지. 가이드 포함 사이트맵 373개. 320px에서 일부 언어의 픽셀 변환기 배지 넘침 보완 |

한국어 전용 연봉·외출 지표는 기존과 같이 한국어에만 제공한다. 가이드는 별도 서버 렌더링 페이지이며 초기 HTML에 본문이 있다. 새 광고 설치나 광고 활성화는 하지 않았다.

## 실제 검증

- `npm test`: 35개 통과. 세액표 646개 구간의 가족 수 1~11 및 구간 양끝, 국세청 예시, 숫자·유니코드·행 비교 경계값 포함.
- `npm run check`: TypeScript와 ESLint 통과.
- `npm run build`: 성공. 오래된 Browserslist 데이터 경고는 남아 있지만 빌드 실패는 아니다.
- `git diff --check`: 통과.
- 운영 방식의 로컬 서버에서 공개 URL 373개, 이전 주소 리다이렉트 360개, 언어별 잘못된 주소 10개 검사: 실패 0. 본문·canonical·hreflang·404 상태 포함.
- Chromium의 320px 및 390px에서 각 373개 페이지 검사: 가로 넘침, 16px 미만 입력 폰트, 페이지 실행 오류 미검출. 모든 입력 상태 또는 실제 iOS·Android를 검증했다는 뜻은 아니다.
- 브라우저에서 `1m→100cm`, `160px→10rem`, 한 줄 삽입 후 1개 추가·3개 일치, 0 기준 증감률 안내 확인.
- HEX `ff0000`의 빨간 미리보기, `#0f0`의 `#00ff00` 정규화, `hello\nworld` 변환, Base64 문법/이진 오류 분리, 비밀번호 미선택 시 즉시 복사 차단 확인.
- 프랑스어 `1,5 USD`에 모의 환율 0.8을 적용해 `1,2 EUR`, 잘못된 금액은 결과 `-` 확인. 이 환율은 재현용 시험 데이터이며 실시간 시세가 아니다.
- 연봉 4,200만 원, 가족 4명, 자녀 2명의 월 소득세 `20,180원` 확인. 잘못된 가족 입력은 `입력 확인 필요` 표시.
- QR의 POST 요청과 PNG 출력, 입력 삭제 시 결과 삭제, 이미지 2개 처리·개별 다운로드 활성화·손상 파일명 안내 확인. 스마트폰 실물 스캔은 하지 않았다.
- 실제 외출 지표 조회에서 한국 시간의 예보 유효 시각과 꽃가루 미지원 표시 확인. 모의 제공원 장애에서는 종합 상태가 `확인 필요`로 전환됨.

## 고유 콘텐츠의 근거

- JSON: `9007199254740993`이 일반 JavaScript 숫자 변환에서 달라지는 사례와 Apps24 포맷터의 숫자 토큰 보존을 자동 테스트로 대조했다.
- 글자 수: 결합 악센트·가족 이모지·줄바꿈의 보이는 글자/UTF-16/UTF-8 값을 실제 집계 함수와 비교했다.
- PNG: Chromium 154에서 직접 만든 320×200 불투명 합성 이미지로 시험했다. PNG 품질 20%와 80%는 3,304바이트 및 동일 SHA-256, WebP 80%는 2,074바이트, JPEG 80%는 3,916바이트였다. 재현 스크립트는 `public/guides/png-fixture.js`에 있다.
- 이 합성 시험은 사진 일반의 압축률이나 화질 평가가 아니다. 실측하지 않은 온라인 자 오차, 실물 QR 스캔 성공률, 일반 사진 비교 수치를 만들어 넣지 않았다.

## 남아 있는 운영 단계

1. GitHub 반영·운영 배포 후 동일 검증을 운영 URL에서 실행해야 한다. 이번 작업은 로컬 파일에만 적용했으며 커밋·푸시·재심사 신청은 하지 않았다.
2. 운영자 정보의 사실 확인, 문의 이메일 실제 수신, 호스팅 요청 로그와 보관 정책 확인이 필요하다. 허위 실명·경력·실험 이력은 추가하지 않았다.
3. Open-Meteo 상업 이용 조건에 맞는 계약 및 서버 전용 `OPEN_METEO_API_KEY` 설정이 필요하다. 광고 활성화 상태에서 키가 없으면 API가 준비 안내를 반환하고, 키가 있으면 고객용 주소를 사용한다. 이는 모의 요청으로 검사했으며 실제 유료 계약·키는 설정하지 않았다. [이용 조건](https://open-meteo.com/en/terms), [API 문서](https://open-meteo.com/en/docs/air-quality-api)
4. 실제 화면 크기 보정·사진 비교·인쇄 QR 스캔을 수행한 뒤 남은 제안 가이드를 추가할 수 있다. 기존 제안 6개를 모두 실험 완료한 상태는 아니다.
5. Search Console 실제 색인·최신 유입 및 AdSense 계정의 상태는 별도 확인해야 한다. 접근 가능과 색인 허용은 실제 Google 색인의 증거가 아니다.

Google의 고유하고 유용한 콘텐츠와 사용 경험 요구에 맞춘 보강이지만, 거절의 내부 평가 내역을 알 수 없으며 승인을 보장하지 않는다. 글 수·글자 수를 승인 기준으로 제시하지 않는다. [사이트 준비도 안내](https://support.google.com/adsense/answer/7299563?hl=ko)
