# 추가 콘텐츠 검증 및 배포 기록

## 콘텐츠

기존 원본 주제 3편에 실제 사진 압축 비교, QR 여백·인쇄 전 점검, 온라인 자 보정 가이드 3편을 추가했다. 총 6개 주제를 10개 언어로 제공한다. 번역을 별개의 원본 실험으로 세지 않는다. 각 언어의 홈·가이드 목록·해당 도구와 사이트맵에서 연결된다.

### 실제 사진 비교

- 입력: NASA Earthrise 사진, 1041×813, 59,190바이트. [사진 출처](https://www.nasa.gov/image-article/apollo-8-astronaut-bill-anders-captures-earthrise/), [미디어 이용 안내](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- 출처 파일 SHA-256: `2a09a810bfd6ec6965bc817f2a2f64dee1bf90cf12caa3936fbeb89825086025`.
- 2026-10-07 Chromium 154, 기본 canvas 인코더 및 고품질 크기 조정. 불투명 원본. JPEG 출력의 흰 배경 및 반올림 방식은 실제 이미지 압축기와 일치한다.
- 같은 크기: PNG 395,915바이트, JPEG 80% 42,674, JPEG 60% 35,582, WebP 80% 27,016, WebP 60% 17,934.
- 크기 50%, WebP 80%: 521×407, 8,224바이트.
- JPEG/WebP 80%는 실제 도구에서 다운로드했고 재현 스크립트와 SHA-256이 일치했다. 원본·두 다운로드 파일을 페이지에서 제공한다.
- JPEG 80% SHA-256: `40599b4c31a330f10bc34cc6d225df978ab3855be1d6743fb1adbdd0729d268e`.
- WebP 80% SHA-256: `0dff4a4c7418291bcba84a7800c0abd2a4f6a816ce819198080d0e3f4a793b31`.
- 재현: 운영 사이트에서 `public/guides/photo-comparison.js`의 스크립트를 브라우저 콘솔에서 실행한다. 임의 웹페이지에서는 상대 파일 경로가 다르다.
- 사진은 NASA가 제공한 입력 자료이며 Apps24가 촬영했다고 표시하지 않는다. 비교 결과는 Apps24의 시험이며 NASA의 승인·보증을 주장하지 않는다. 한 사진의 결과로 평균 압축률이나 객관적 화질 점수를 주장하지 않는다.

### QR

- 이전 여백 설정은 bwip-js의 포인트 단위 때문에 12픽셀, 2모듈이었다. `padding: 8`로 변경해 scale 3에서 24픽셀, 4모듈 확보.
- URL `https://example.org/apps24-qa`: PNG 222×222, 사방 여백 24픽셀.
- 텍스트 `Apps24: 한글 ✓`: PNG 198×198, 사방 여백 24픽셀.
- ZXing-C++ 3.1.1/Pillow 12.3.0에서 모두 입력 원문과 정확히 일치. 재현 스크립트 `scripts/verify-qr-guide.py` 및 API 회귀 테스트 추가.
- 디지털 파일 판독만 수행했다. 실제 인쇄·카메라 스캔 성공률은 검증하지 않았으며 가이드에 명시했다. 인쇄 절차는 사용자가 최종 재질·크기·거리·조명에서 확인하도록 안내한다.

### 온라인 자

- `pixelsPerCentimeter`와 눈금 계산의 240·342 CSS픽셀 예시를 자동 테스트로 검증했다.
- 화면 기준 물체의 정렬, 별도 실물 자 교차 확인, 확대율·기기 변경 후 재보정 절차 제공.
- 실물 카드나 실물 자로 측정하지 않았으며 물리적 오차 범위를 인증하지 않는다. 5.2cm/4%는 계산 예시이고 실측값이 아니다.

## 검증 및 배포

- `npm test`: 39개 통과. 다국어 완전성, 사진 다운로드의 크기·해시, 보정 계산, QR 여백 포함 PNG 크기 검사 추가.
- `npm run check`: 타입 검사·린트 통과. `npm run build` 성공. 오래된 Browserslist 데이터 경고는 비차단 경고로 남는다.
- 운영 방식 로컬 서버: 사이트맵 403개 페이지, 이전 주소 360개 리다이렉트, 잘못된 주소 10개 404 검사 통과.
- Chromium 320px·390px에서 각각 403개 페이지를 검사했고 가로 넘침·작은 입력 글자·페이지 실행 오류는 발견되지 않았다. 모든 입력 상태나 실제 모바일 기기를 시험한 것은 아니다.
- 최신 운영 방식 로컬 API에 대한 QR 판독·사방 여백 검사 통과. 한국어 사진 가이드의 모바일 전체 화면도 시각 확인했다.

GitHub 메인에 위 검증을 통과한 변경을 반영하고 연결된 Vercel 배포를 확인하는 순서로 진행한다. 운영 배포 결과는 작업 응답에서 별도 보고한다. 이전 로컬 검증 기록은 `adsense-implementation-2026-10-07.md`에 있다. 승인이나 재심사 신청은 이번 작업 범위가 아니다.
